# CyberKeyLab

Educational cybersecurity project for demonstrating keyboard-event monitoring and
system activity logging in an isolated, authorized lab environment.

## ⚠️ Ethical Use

This project is intended only for:

- Your own computer
- Authorized security labs
- Cybersecurity education
- Controlled demonstrations

Do not use it to monitor another person's device, credentials, private messages,
clipboard contents, webcam, or screen without their explicit permission.

## Technologies

- Python
- pynput
- PyAutoGUI
- OpenCV
- PyGetWindow
- Pyperclip
